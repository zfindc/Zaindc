# Make the best-looking food picture — entry

`main.py` copies the bundled artwork `art.jpg` (a steaming bowl of
tonkotsu ramen with a noodle pull, jammy egg and seared chashu,
photographed in dramatic warm light) to `/output/entry.png`.
Python 3.13, standard library only, no network, deterministic output.
Artwork: 1024x1024 JPEG, under 1 MiB, as required.
